## Сообщение об уязвимости

Если вы обнаружили уязвимость в этом проекте:

1. **Не создавайте публичный issue**.
2. Отправьте описание на `security@example.com`. **Перед публикацией замените на реальный адрес.**
3. Включите:
   - Краткое описание уязвимости
   - Шаги воспроизведения
   - Оценку влияния (CVSS, если доступна)
   - Предложение по исправлению (опционально)

Ответ ожидайте в течение 72 часов. Исправление публикуется после анализа и, при необходимости, выпуска патча.

## Практики безопасности

- Пароли магазинов хранятся в зашифрованном виде (XSalsa20-Poly1305).
- Ключ шифрования задаётся через переменную окружения, не включается в репозиторий.
- Сессии используют HttpOnly, Secure, SameSite=Lax cookies.
- Nonce для входа одноразовые с TTL 5 минут.
- `hash_equals()` для constant-time сравнения подписей.
- SSRF-защита: блокировка private IP и loopback (кроме тестового режима).
- `composer audit` запускается еженедельно через GitHub Actions.
- Semgrep SAST запускается на каждый PR и push в основную ветку.
